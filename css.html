What is CSS?

CSS stands for Cascading Style Sheets. It is used to change how a webpage looks.

What can CSS do?

CSS can change text colours, background colours, font sizes, spacing and the layout of a webpage.

Example of CSS

        h1 {
        color: blue;
        font-size: 30px;
        }

This example makes all h1 headings blue and changes their size.

Try it yourself

Open your HTML page and use CSS to change the heading colour and the background colour.

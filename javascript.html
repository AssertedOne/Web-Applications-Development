What is JavaScript?

JavaScript is a programming language that makes webpages interactive.

What can JavaScript do?

JavaScript can respond when someone clicks a button, display messages and change webpage content.

Example of JavaScript

alert("Hello! Welcome to my website.");

This example displays a message in a small pop-up box.

Try it yourself

Try making a button that displays a message when someone clicks it.
